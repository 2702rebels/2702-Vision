Detailed Description

template<ObjLatencyReporting LatencyReporting, ObjVideoDebuggingInfo VideoDebugging, ObjUseGui UseGui, ObjMultipleObjectDetection MultipleObjectDetection, ObjSendPackets SendPackets, ObjUseOutputFiltering UseOutputFiltering>
class ObjectFrameProcessor< LatencyReporting, VideoDebugging, UseGui, MultipleObjectDetection, SendPackets, UseOutputFiltering >

Class for producing object detections from inputted frames.

Runs a processing algorithm of filtering to extract only objects in a final frame and sending the positions and angles of those objects to the RoboRIO in order to be acted on

Template Parameters
LatencyReportingWhether or not to print the latency to the filtered frame and the console
VideoDebuggingWhether to add additional annotations to the frame for debugging
UseGuiWhether to display the GUI replay elements like trackbars for certain config values and other elements
MultipleObjectDetectionWhether to turn on or off the ability to detect multiple objects in a single frame. When off, the biggest element is selected to be the only potential object in thef rame. When on, all objects are treated as potential objects
SendPacketsWhether to attempt to send packets to the roboRIO for it to use
UseOutputFilteringWhether to filter the outputted object distances and angles through m_distanceFilter and m_angleFilter before sendingt to the roboRIO

Filters the image into a mask where each pixel is either able to be part of a valid detection(white) or not(black).

To tune these values, change them in the processorSettings.txt file.

Parameters

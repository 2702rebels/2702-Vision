Detailed Description

Packet holding multiple object detections and other header info.

Also has an associated WPI struct for serialization and transmission to the roboRIO by UDP packet

Parameters
keyA magic value used to check the integrity of the packet, defined as PACKET_KEY
versionNumberVersion number used to check the validity of the packet as well, defined as PACKET_VERSION
timeTimestamp of packet, microseconds from NetworkTables adjusted for server
countThe number of valid object detections in this packet
coral1The first detection
coral2The second detection
coral3The third detetion
coral4The fourth detection
key- Magic number used as a packet corruption measure, use PACKET_KEY to set.
versionNumber- Version number used to prevent reading packets from wrong serialization version, use PACKET_VERSION to set this.
timestamp- Server-adjusted timestamp obtained from NetworkTables in microseconds.
count- How many of the corals have valid data in them, i.e 2 means coral1 and coral2 have data.
coral1- The first coral, can use ObjectDetectionPacket() to initialize empty.
coral2- The second coral, can use ObjectDetectionPacket() to initialize empty.
coral3- The third coral, can use ObjectDetectionPacket() to initialize empty.
coral4- The fourth coral, can use ObjectDetectionPacket() to initialize empty.

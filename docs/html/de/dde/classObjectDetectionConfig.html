Detailed Description

template<typename T>
class ObjectDetectionConfig< T >

A class to encapsulate a protobuf message representing a configuration for the purposes of syncing its values in memory, on disk and in networktables.

Warning
Your protobuf message can only contain certain allowed types (see ObjectDetectionConfigValue tparam docs)
You must add template definitions for your config message to ObjectDetectionConfig.cpp or you will get linker errors
Template Parameters
Tthe type of the protobuf message configuration that this class is encapsulating

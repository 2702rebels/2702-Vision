Detailed Description

template<typename T>
class NetworkTopicGeneric< T >

Abstraction for getting and pushing values to network tables topics using a template class.

Used for keeping ObjectDetectionConfigValue in sync with networktables

Template Parameters
Tthe type of the value to sync. Can be int32_t, int64_t, float, double, bool, std::string or a vector of any of those

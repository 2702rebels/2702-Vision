Detailed Description

A class for synchronously writing to a vision logfile.

Version
2.0
Warning
This class is not thread safe in any manner
This class will likely cause crashes if you provide invalid cv::Mat instances to WriteFrame

This class follows RAII principles, logfile is closed when the writer instance is deleted

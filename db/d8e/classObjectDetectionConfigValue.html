Detailed Description

template<typename T>
class ObjectDetectionConfigValue< T >

A configuration field which syncs the 3 config sources: program memory, disk, and networktables.

Also offers support for adding a callback to be executed when the value is changed

Template Parameters
Tthe type of the value to sync. Can be int32_t, int64_t, float, double, bool, std::string or a vector of any of those
